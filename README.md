# ALEKSEI — Portfolio Website

A bilingual portfolio website for ALEKSEI, featuring project showcases, the SkyLodge hotel platform, and contact links.

## Run locally

- Install [pnpm](https://pnpm.io/installation) and Node.js 20 or newer.
- Run `pnpm install`.
- Run `pnpm dev` to start the development server.
- Run `pnpm build` to create a production build in `dist/`.

The source and required image assets are kept at the repository root; this repository contains the website only.
